
# Environmental Action Network - EAN

Environmental Action Network (EAN) is a WebApp platform where Users can report environmental issues (pollution, deforestation, etc.) and collaborate on finding the right solutions. It can also be regarded as a social media for the environment.



## Tech Stack

- Html
- CSS
- Python
    - Flask
